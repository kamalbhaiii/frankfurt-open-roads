# Frankfurt: Open Roads (v0.1.0)

An open-world driving game that runs in the browser, set in Frankfurt's real city centre. The city is built from OpenStreetMap data, and the sun, moon and weather follow the real time and live weather in Frankfurt. Everything is free and open source: no API keys, no paid services, and every model, sound and piece of music is generated by code.

## Play
The game is a folder build served by a small local web server. Opening `dist/index.html` directly won't work, because browsers block textures loaded from a double-clicked file.

- **Easiest:** double-click **`Play.bat`**. It installs dependencies and builds the game if needed, then opens it in your browser.
- **Terminal:** `npm start` builds the game and opens it; `npm run serve` opens an existing build. Stop the server with Ctrl+C.

Graphics adapt to your PC automatically (**Settings → Graphics quality → Auto**). You can also pick Low, Medium, High or Ultra.

To host it online, upload the whole `dist/` folder to GitHub Pages, Netlify or Cloudflare Pages.

## What's in the game
- **Story:** four missions for Kurier Hartmann, a courier firm with flexible ethics. Find Lena at the yellow **L** on the map.
- **Side activities:** two street races with gold/silver/bronze times, taxi fares and parcel deliveries (press **J** in a taxi or van), and 25 hidden postcards.
- **Heat (wanted) system:** levels 0–5 with police pursuit cars that route through the street network, ram you and box you in. Officers get out and chase you on foot. To lose the heat, break line of sight until the stars stop flashing, or use a respray garage.
- **Health and armour:** health regenerates to 50%. There are health pickups at hospitals and armour at police stations, plus fall, crash and pedestrian-impact damage. When you're knocked out or arrested, a sequence plays and you respawn at a hospital or police station for a fee.
- **Vehicles:** 8 types with damage, smoke, a working speedometer, automatic indicators, police sirens, a horn, a first-person cockpit camera and generative radio. The radio stations are Mainhattan 128 (techno), Apfelwein Lounge (lo-fi) and Nachtschicht FM (synthwave).
- **Living city:** traffic that follows lanes, rounds corners, indicates and stops at red lights. Pedestrians flee and witness crimes. Lamps get knocked over, there are avenue trees, and live day/night and weather.
- **Map and GPS:** a zoomable, pannable full map with a legend and waypoints (click to set, right-click to clear). The GPS draws the shortest legal route on the minimap, respecting one-way streets in a car.
- **Menus:** a loading screen with an illustrated skyline and tips, a title menu (continue, new, load), and a pause menu with Map, Brief, Stats, Settings, Controls and Game tabs.
- **Saving:** three save slots plus an autosave after story missions, and a safehouse in Westend where you can sleep and save.
- **Settings:** graphics, FOV, view distance, units, volume per channel (effects, radio, ambience), sensitivity, invert-Y, rebindable keys, traffic and pedestrian density, weather and time mode. Settings are saved in the browser.
- **Input:** keyboard and mouse, gamepad (standard mapping) and touch controls.

## Controls (default, rebindable)
| Action | Key |
|---|---|
| Move / drive | W A S D or arrows |
| Look | Mouse (click to capture) · wheel to zoom |
| Sprint · jump / handbrake | Shift · Space |
| Enter / exit / carjack | F |
| Horn (siren in police cars) | H |
| Camera · look behind | V · C |
| Radio station · vehicle job | Q · J |
| Map · pause | M · Esc |
| Flip vehicle / unstuck · time speed | R · T |

## Project layout
```
src/
  main.js               boot sequence, loading stages, main loop
  core/                 config, math, events, input, settings, storage, shared context
  world/                data loading, city meshes, streets, furniture, sky, weather,
                        environment (time/lighting), physics, road network (graph + A*)
  actors/               characters, vehicles, traffic AI, pedestrians, player, police
  gameplay/             game flow, heat level, missions (+ mission data), services
                        (hospitals, garages, safehouse, pickups, postcards), GPS,
                        camera rig, markers/blips, stats, places
  audio/                synthesised sound effects + generative radio
  ui/                   loading screen, HUD, minimap, map renderer, map screen, menus, styles.css
  index.html            page skeleton (styles and script are inlined at build time)
assets/models/*.glb     generated 3D models
data/*.json.gz          OpenStreetMap extract (© OpenStreetMap contributors, ODbL) + precomputed streets
tools/make-models.mjs   generates the models (tools/models/{common,cars,characters,props}.mjs)
tools/build-streets.cjs generates data/streets.json.gz from the OSM extract
tests/unit.test.mjs     unit tests for pure logic (routing, heat, math)
tests/smoke.mjs         headless-browser end-to-end test
build.mjs               bundles everything into dist/index.html
```

## Development
```
npm install
npm run build          # dist/index.html (minified)
npm run build:dev      # unminified with source maps
npm test               # unit tests
npm run test:smoke     # builds, then plays through the game in headless Chrome (set CHROME_PATH if needed)
npm run lint           # ESLint
npm run format         # Prettier
npm run models         # regenerate all models; or: node tools/make-models.mjs cars|characters|props
```

### Replacing models
Export a `.glb` with the same file name, then keep these naming rules:
- **Cars:** wheel nodes named `wheel_FL/FR/RL/RR` with pivots at the hubs, +Z forward, ground at y = 0, and +X as the car's left side. Materials named `body_vc`, `headlight`, `taillight`, `indicator_L`/`indicator_R`, `siren` and `taxi_sign`. Keep the `userData` fields documented in `tools/models/cars.mjs`.
- **Characters:** clips named `idle`, `walk`, `run`, `jump`, `swim`, `sit`, `fall` and `wave`, and a `userData.palette` for recolouring.
- **Props:** `lamp_lens` on the lamp, and `lens_red`/`lens_amber`/`lens_green` on the traffic signal.
